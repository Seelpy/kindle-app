# Ещё пять для KOReader

Безопасный каркас пользовательского плагина. Он пока показывает только стартовый экран и не выполняет сетевые или системные команды.

Для прямого запуска с домашнего экрана Kindle скопируйте `kindle/EschePyat.sh`
в `/mnt/us/documents/`. Карточка «Ещё пять» запустит KOReader как движок и
сразу откроет экран плагина.

Плагин не следует копировать на настоящее устройство, пока не подтверждены модель Kindle, версия прошивки, совместимость jailbreak и план восстановления.
