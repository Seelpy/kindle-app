# Архитектура «Дальше Live»

## Компоненты

- `native-macos/` — нативный SwiftUI-клиент и безопасный симулятор Kindle.
- `KindleScreenShare.swift` — опциональный просмотр framebuffer Scribe по SSH с преобразованием grayscale-кадров средствами macOS.
- `koreader/dalshe.koplugin/` — минимальный пользовательский плагин KOReader без установки на устройство.
- `src/` — интерактивный визуальный прототип для быстрой проверки продукта.

## Целевой обмен данными

1. KOReader сообщает Mac только название документа, стабильный хэш, позицию, прогресс и события перелистывания.
2. Mac хранит общую модель состояния локально и назначает монотонный `revision`.
3. При потере сети обе стороны продолжают работать локально.
4. После восстановления соединения побеждает более новая ревизия; заметки объединяются, а не удаляются.
5. Текст книги и содержимое страниц не передаются.

На этапе симулятора сетевой транспорт намеренно отсутствует. Следующий этап — локальный протокол с явным сопряжением устройств.
