# Архитектура «Ещё пять»

## Компоненты

- `native-macos/` — единственное пользовательское приложение: нативный SwiftUI-клиент для Mac.
- `KindleScreenShare.swift` — опциональный просмотр framebuffer Scribe по SSH с преобразованием grayscale-кадров средствами macOS.
- `src/` — интерактивный визуальный прототип для быстрой проверки продукта.

## Целевой обмен данными

1. Kindle остаётся обычной читалкой и не показывает интерфейс «Ещё пять».
2. Mac получает только изображение экрана Kindle по локальному SSH-соединению.
3. Состояние пятистраничной сессии и заметка хранятся только на Mac.
4. При потере сети чтение на Kindle не блокируется; просмотр экрана можно подключить повторно.

На этапе симулятора сетевой транспорт намеренно отсутствует. Следующий этап — локальный протокол с явным сопряжением устройств.
