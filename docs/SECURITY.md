# Безопасность

## Зафиксированные ограничения

- Никаких изменений настоящего Kindle до проверки модели и прошивки.
- Никакого постоянного входа как `root`.
- Никакого `StrictHostKeyChecking=no`.
- Никакого запуска команд через `shell: true` с пользовательскими параметрами.
- Никакого доступа из интернета: только локальная сеть и сопряжённые устройства.
- Текст книг, заметки и статистика не отправляются во внешние сервисы.
- Framebuffer может использоваться только в диагностическом режиме чтения.

## Угрозы, которые нужно закрыть до сетевого MVP

- подмена Mac или Kindle в локальной сети;
- повтор старого сообщения синхронизации;
- раскрытие заметок соседнему устройству;
- повреждение состояния при разрыве соединения;
- оставшийся SSH-сервер после диагностики;
- команды с повышенными привилегиями;
- автоматическое обновление Kindle после подготовки jailbreak.

Для сопряжения планируется одноразовый код, взаимная идентификация устройств и хранение секретов в Keychain на Mac.
